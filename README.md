# Lecteur 60 i/s (application native)

Lancer depuis les sources : `pip install -r requirements.txt` puis `python app.py`.
Exécutable : onglet Actions du dépôt → dernier run « Build » → Artifacts (Windows, macOS, Linux).
Les exports sont écrits à côté des fichiers originaux (`nom_60fps.mp4`). ffmpeg est fourni par le paquet imageio-ffmpeg.
